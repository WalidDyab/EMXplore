PSU fixed telescope archive

What data products exist, in what formats, at what processing stage, and what can eventually be downloaded. Awaiting ingestion: none of these files are connected yet.

Reading this page. This is the archive architecture for the PSU fixed telescope. The stages below are described from the project's own account of its historical data. No files from this station have been ingested into the portal, so nothing here can be downloaded. Every stage carries a status.

Historical lineage

A0 – A3: the data as they exist

Source lineage of the historical PSU fixed-telescope data.

  1. A0

    A0: Original recorded spectra

    Measured Awaiting ingestion

    Averaged spectra: frequency versus relative amplitude, with the receiver/background response already corrected. One spectrum per file.

    • TXT
  2. A1

    A1: Aggregated observation bundles

    Derived later Awaiting ingestion

    The original spectra gathered into larger files, approximately 1000 spectra per file. Repackaging, not new measurement.

    • MAT
  3. A2

    A2: Historical RA / LST-corrected bundles

    Derived later Awaiting ingestion

    Bundles to which the project's historical Right Ascension / Local Sidereal Time correction was applied. See Solar Time → Sidereal Time → Right Ascension.

    • MAT
  4. A3

    A3: PSU station master dataset

    Derived later Awaiting ingestion

    The station's historical data combined into one MATLAB structure.

    • MATLAB structure

Modern reprocessing

P0 – P4: the reprocessed scientific archive

Planned. None of these products exist yet, and none will be presented as measured data.

  1. P0

    P0: Faithfully decoded historical observation

    Derived later Planned

    The historical files decoded into open formats with no scientific change, so the original measurement is preserved exactly.

  2. P1

    P1: Modern celestial-coordinate reconstruction

    Derived later Planned

    Time stamps and station position turned into celestial coordinates again with documented, modern methods.

  3. P2

    P2: Doppler / spectral-frame product

    Derived later Planned

    Frequency axis converted to velocity in stated reference frames. See Frequency → Velocity.

  4. P3

    P3: Absolute calibration (when scientifically valid)

    Derived later Calibration under validation

    Relative intensity converted to temperature, only if the assumptions and uncertainties can be established for the historical receiver. See Relative Intensity → Temperature.

  5. P4

    P4: Community / FITS archive product

    Derived later Planned

    Standards-based reprocessed spectra with provenance, celestial coordinates, velocity reference frames, calibration state and metadata.
